# מודל עלויות לפי גודל אירוע

> אומדן ראשוני. מחירי ה-API הם הערכות סבירות לפי מחירון ציבורי (אוק' 2026) ואינם מאומתים מול דפי המחיר הרשמיים — לאמת לפני הצעת מחיר ללקוח. שער: $1 = ₪3.7.

## הנחות
- שימוש: 60% מהאורחים (טווח סביר 40–70%; בבר מצווה בדרך כלל 50–60%).
- לכל משתמש פעיל: תמונה (1.5 ניסיונות בממוצע, ~$0.06 לניסיון, מודל תמונה כמו gpt-image / Gemini image), LLM לניתוח וקונספט (~$0.03), 40% מייצרים גם שיר (~$0.20 דרך ספק API לא רשמי של Suno או חלופה כמו ElevenLabs Music / Udio), קול/כריכה (~$0.02). סה"כ ≈ $0.22 למשתמש פעיל.
- שרת ואחסון: VPS/Cloud Run + S3 + CDN, $5–25 לאירוע לפי נפח. ועוד $10 שונות (דומיין, SMS, ניטור).
- עמדה פיזית: מסך מגע 21" ($400) + מצלמה ($60) + מיקרופון ($40) + מיני-PC ($250) ≈ $750, פחת על 40 אירועים, + $15 הובלה לעמדה. עמדות: 1/1/2/3/4.
- מגנטים: 70% מהפעילים מקבלים מגנט, ~$0.60 ליחידה (מדיה למדפסת dye-sub 4x6 או חומר גלם + גזירה). מדפסת: ~$1,200 חד פעמי (לא כלולה למעלה).
- מפעיל: $40 לעמדה (עלות אלינו).
- בלוק/הדפסה תלת ממד: ~$3 ליחידה, כתוספת פרימיום ל-10% מהפעילים (בנפרד, לא בסיכום).

## מסקנות
- חבילה דיגיטלית בלבד (QR + תמונה + שיר) היא כמעט נטו תוכנה: עלות ₪130–620, מרווח ~90%. כאן העסק הכי טוב ואפשר למכור גם לצלמי מגנטים כרישיון (למשל ₪800–2,000 לאירוע, או מנוי חודשי).
- עמדה עם מגנטים מוסיפה חומרה, מפעיל ומגנטים: מרווח ~77–83% ועדיין טוב. עלות לאורח פעיל ≈ $1.2 ($0.22 AI, השאר פיזי).
- AI הוא פחות מ-15% מהעלות בחבילה הפיזית, ולכן שווה להשתמש במודל איכותי ולא לחסוך שם.
- בלוק תלת ממד: ₪100–670 עלות לאירוע, מתאים רק כתוספת בתשלום (₪25–40 ליחידה).
- ללא מכונת מגנטים אוטומטית (מכירת פחיות): השקעה $8–15K, מצדיקה את עצמה רק מעל ~15 אירועים בשנה. להתחיל עם מדפסת + גוזר ידני.
- לא כולל: הובלה לאירוע, ביטוח, מע"מ, זמן פיתוח, ושיווק.
